* 🚨 Severity Classification

# 📊 What the Demo Shows

The demonstration covers the major functionality of the project:

### 1️⃣ Log Input

Loading and processing log files containing system or application events.

### 2️⃣ Log Parsing

Extracting information such as:

* Timestamp
* Log level
* Message
* Event information

### 3️⃣ Anomaly Detection

Identifying unusual patterns, spikes, and abnormal log behavior.

### 4️⃣ Severity Classification

Detected events are categorized as:

```text
🔴 CRITICAL
🟡 WARNING
🟢 INFO
```

### 5️⃣ Visualization

Displaying detected anomalies through charts and visual reports.

### 6️⃣ Final Analysis

Generating a summary of processed log entries and detected anomalies.
